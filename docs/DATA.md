# 데이터 인수인계

- 정제 결과: `www/data/places.json` 7,981개 (대피소 6,947 / 마트 1,034)
- 좌표 없는 원본 19개는 보존하지만 지도·현재 지도 범위 목록에서는 제외
- 대피소: 서울 25구와 경기 31시군 공개 파일의 사용 중 시설. 이름·주소 중복 정리, 좌표계 변환. 지하 여부는 명칭 표기를 기반으로 하므로 모두 현장 확인한 시설은 아님
- 마트: 서울 대규모점포/기타식품판매업의 영업 중 자료를 선별하고 OSM 가게 노드로 보완. 서점 오분류 일부 제거. 누락·중복 가능
- 지도: Geofabrik South Korea OSM 2026-10-31 스냅샷, Natural Earth 육지 경계
- `tiles/7`: 축소 개요, `tiles/13`: 상세 구역. 런타임은 현재 화면의 타일만 읽고 메모리 캐시를 제한
- 지하철: OSM 관계 기반 24개 수도권 노선. 역 노드는 전국 1,328개. 실제 운행 상태나 전체 역의 완전성을 보장하지 않음
- 원본 데이터 링크와 라이선스: `www/data/manifest.json`
- 지도 출처: https://www.openstreetmap.org/copyright / https://download.geofabrik.de/asia/south-korea.html / https://www.naturalearthdata.com/
